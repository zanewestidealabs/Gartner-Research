## Back-cover blurb options

### Blurb 1 — Flagship version

For two decades, security operations has been organized around a familiar labor model: alerts arrive, analysts triage, complex cases escalate, and humans remain the default processing layer for judgment and action. That model is now breaking.

_The End of the Tiered SOC_ argues that enterprise security operations is undergoing architectural substitution, not incremental feature evolution. The systems emerging at leading programs are not simply analyst workflows enhanced with AI. They are governed control systems built on continuous sensing, machine reasoning, bounded agent execution, runtime governance, and a shared operational intelligence spine.

Using the Agentic Security Operations Adoption Framework (ASAF), this book explains how the transition can be staged, assessed, and compared across six maturity levels, three operating planes, and eleven strategic dimensions. It shows why some vendors enable stage advancement, why others remain merely useful, and why entire categories are becoming architecturally exposed.

This is a book for CISOs, security product leaders, platform architects, and market strategists who need a sharper language for what is ending, what is replacing it, and what decisions matter now.

### Blurb 2 — Executive and buyer version

Security leaders are being told that AI will transform the SOC. But most of that language is too vague to guide architecture, investment, or vendor selection.

_The End of the Tiered SOC_ offers a more precise claim: the analyst-tier model that governed security operations for twenty years is being replaced by a new architecture built around sensing, reasoning, control, governance, and shared operational intelligence. This shift is already measurable. It can be staged. And it changes how platforms should be evaluated.

Through the ASAF framework, this book helps readers distinguish between products that help enterprises advance into the new operating model and products that merely optimize friction inside the old one. The result is not a generic AI-in-cyber manifesto, but a concrete operating-model map for the next era of security operations.

### Blurb 3 — Product and market strategy version

Feature comparison is becoming the wrong way to understand the future of security operations.

In the emerging model, the real differentiators are reasoning depth, governance architecture, graph contribution, and participation in the live control loop of the operation. _The End of the Tiered SOC_ explains why those shifts matter, how they can be measured, and which product categories are structurally advantaged—or exposed—as enterprise programs advance beyond Stage 1.

For security product leaders, strategists, and platform architects, this book provides a framework for understanding the move from alert-centric operations to governed autonomy, and for deciding where a product truly belongs in the system that is replacing the traditional SOC.

## Author-style framing paragraph

This book is not an argument that AI will merely improve security operations. It is an argument that the operating model itself is being rebuilt. The old structure was optimized for distributing human investigative labor. The new structure is optimized for producing governed system behavior. That difference changes everything from product design and vendor relevance to governance, metrics, and the role of the human operator.
