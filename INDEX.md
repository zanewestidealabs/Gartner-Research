## 🎯 Quick Reference Cards

### File Locations
```
app.py                 ← Flask backend
requirements.txt       ← Dependencies
run.bat               ← Windows startup

templates/index.html   ← Main page
static/style.css      ← Styling
static/app.js         ← Interactivity

vendor3-3.json        ← Vendor data
schema3-3.json        ← Taxonomy
```

### Common Commands
```bash
# Install dependencies
pip install -r requirements.txt

# Start server
python app.py

# Open in browser
http://localhost:5000

# Stop server
Ctrl+C

# Change port
python app.py --port 5001
```

### Keyboard Shortcuts
```
Ctrl+F       → Search in browser
Ctrl+A       → Select all
Ctrl+C       → Copy
F5           → Refresh page
F12          → Developer tools
Ctrl+Shift+R → Hard refresh
```

### Filter Tips
```
Search:  Type in search box for free-text
Filters: Click filter tags to narrow results
Click:   Click table values to instantly filter
Reset:   "Reset All" button clears everything
Combine: Multiple filters work together (AND)
```

### Keyboard Navigation
```
Tab        → Move between elements
Enter      → Activate buttons
Space      → Check checkboxes
Escape     → Close modals
Arrow Keys → Scroll in tables
```

## 🎯 Quick Answers

### Q: Where do I start?
**A**: Read [QUICK_START.md](QUICK_START.md) and open http://localhost:5000

### Q: How do I search?
**A**: Type in the search box for free-text, or use filter groups

### Q: How do I filter?
**A**: Click on any value in the table or expand filter groups

### Q: What do the pillar scores mean?
**A**: Read the Legend tab in the app (click "Legend" in left navigation)

### Q: Can I export data?
**A**: Select table rows and copy (Ctrl+C) to paste in Excel

### Q: How do I toggle dark mode?
**A**: Click the moon icon (🌙) in the bottom-left

### Q: Where is the vendor data from?
**A**: It's in vendor3-3.json - 60+ DFIR vendors with capability scores

### Q: Can I add new vendors?
**A**: Edit vendor3-3.json and restart the server

### Q: What's the scoring scale?
**A**: 1 (manual) to 5 (fully agentic) for AI automation level

### Q: Is it mobile friendly?
**A**: Yes! Works on all device sizes - fully responsive
